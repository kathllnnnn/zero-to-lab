# ZERO → LAB 🧬
### A Custom Guide to Biology, Genetic Engineering and Synthetic Biology
*Volume 1 — Foundations & Core Molecular Biology*

> **Do-first. No memorization. Built for understanding, not exams.**

## 📢 PROJECT STATUS & IMPORTANT NOTE
**Hey! If you are reading this, welcome to the early-access launch of ZERO → LAB.** 

This guide is custom-built because traditional biology textbooks are broken. They force you to memorize a mountain of facts before you even understand *why* they matter. This guide flips the script.

* **Why is it short right now?** I am publishing this first version exactly as it is (Module 0) to gather immediate feedback from the bio-hacking, synthetic biology, and open-source community. I want to know if this active-learning style works for you before deploying the next chapters.
* **How to contribute:** If you love this approach and want to see the remaining modules (PCR, Gel Electrophoresis, CRISPR, Cell Culture) built out in this exact "no-BS" style, open an **Issue**, start a **Discussion**, or let me know what you think! Your feedback directly dictates the next update.

## 🏭 MODULE 0 — The Cell as a Factory

* **Nucleus** = The blueprint archive. Firewalled. Originals never leave.
* **DNA** = The blueprints. Double copies of every sheet (redundancy).
* **mRNA** = A photocopy of one page, walked to the shop floor.
* **Ribosomes** = The assembly robots.
